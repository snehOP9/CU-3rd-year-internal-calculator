# Browser support

The calculator is a client-side HTML, CSS, and JavaScript application and does not require a build step.

## Recommended browsers

Use a current version of one of these browsers:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

## Why current browsers matter

The interface uses modern CSS features such as `color-mix()`, CSS custom properties, backdrop filtering, and responsive layout primitives. Older browsers may render the visual theme differently even when the calculator logic still works.

## If the UI looks incorrect

1. Update the browser to a current stable release.
2. Reload the page without a cached copy.
3. Try the light theme to distinguish layout problems from theme-specific styling.
4. Report the browser name/version and the affected screen when opening an issue.

The calculator remains usable without installing Node.js or any build tools.
